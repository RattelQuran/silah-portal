# DESIGN_SYSTEM — صلة

## الهوية المعتمدة (مصدرها: إعادة تصميم الموقع، PR #1 في `silah`، ومواصفات `silah-voices-motion/AGENTS.md`)

**الفكرة المركزية: «الخيط الواصل».** خيط رفيع قرمزي (ونسخة ذهبية) يُرسم أثناء التمرير ويربط العناصر، مع **القوس المدبّب** (الإسلامي) إطارًا للبطاقات الرئيسية. هادئ، دافئ، غير مزدحم. لا إيموجي في الواجهات التسويقية، ولا صور وجوه أو رسوم أطفال جاهزة.

- النص: **IBM Plex Sans Arabic** (400/500/600).
- الآيات: **Amiri Quran**.

### الشعار
`logo.jpg` مربع، داخل بلاطة بيضاء دائرية أو مستديرة الزوايا. لا يُعاد تلوينه ولا يُمطّ.

## الوضع الحالي للبوابة (فجوة موثّقة)
البوابة بُنيت **قبل** إعادة تصميم الموقع، وتستخدم:
- خلفية رمادية `#ECECF0` وبطاقات بيضاء («ورق مقصوص»).
- خط **Tajawal** بدل Baloo/IBM Plex.
- نفس الأزرق `#1236A0` والقرمزي `#C8174D` (متوافقان مع الهوية).
- لا ذهبي، لا كريمي، لا قوس ولا خيط.

النتيجة: ولي الأمر ينتقل من موقع كريمي ذهبي إلى بوابة رمادية بخط مختلف. **لم تُغيَّر البوابة** التزامًا بقاعدة عدم تغيير الهوية دون اعتماد. ثلاثة اتجاهات مقترحة بملفات CSS تجريبية في `design-directions/` (a «الخيط الواصل»، b «المحراب»، c «السكينة»، وcommon للخطوط والرموز المشتركة)، ولقطاتها في صفحة المقارنة. القرار D-11 في DECISION_LOG.md.

## رموز البوابة الحالية (`index.html :root`)
`--paper #ECECF0` · `--sheet #FFF` · `--navy #1236A0` · `--ink #1B2236` · `--muted #5A6378` · `--line #DCDEE7` · `--crimson #C8174D` · `--sky #DCEBFA` · `--ok #1F8F6A` · `--late #B87F00` · `--miss #C8174D` · `--exc #64748F`.
ألوان الحالات ثابتة ويجب الإبقاء على دلالتها عند أي مواءمة: حضر = أخضر، تأخر = كهرماني، غاب = قرمزي، اعتذر = رمادي مزرق، غاب المعلم = أزرق، تأجلت = بنفسجي `#7A5AA8`.

## مبادئ الواجهة الإدارية
- شاشة المعلم مصممة للهاتف أولًا: بطاقة لكل حصة بأزرار حضور كبيرة.
- الجداول المالية داخل `.tscroll` للتمرير الأفقي على الهاتف بدل كسر التخطيط.
- النوافذ المنبثقة «ورقة سفلية» على الهاتف ومركزية على الشاشات العريضة.
- تأكيد الحذف بضغطتين بدل نوافذ `confirm()`.
