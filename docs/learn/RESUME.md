# نقطة الاستئناف: القسم التعليمي في صلة

آخر تحديث: 27 نوفمبر 2026، نهاية المرحلة 02 · الفرع `learn/phase-1` (لم يُدمج ولم يُنشر).

## أين نحن

النموذج يعمل محليًا ويُفتح من `learn/index.html`. فيه:

- 12 محركًا قابلًا للعب.
- 10 أقسام.
- مدينة صلة.
- 4 ألعاب دكان.
- لوحات وليّ الأمر والمعلمة.
- مصنع المحتوى.

الحفظ في `localStorage` فقط (المفتاح `silah-learn-v2`).

## تشغيل محلي

```bash
cd silah-portal
python3 -m http.server 8765
# افتح http://127.0.0.1:8765/learn/
```

## واجهة المحرك (لإضافة محرك جديد)

```js
ENGINES.x = {
  name, controls,
  total(lesson),           // عدد خطوات التقدم
  fn(root, lesson, api) {  // يرسم داخل root ويعيد دالة إيقاف
    // api.progress(n) · api.prompt(text) · api.say(text) · api.finish({correct, wrong})
    window.__eng = { /* حالة للقراءة في الاختبارات */ };
    return () => {/* stop */};
  },
};
```

ثم أضف حقوله في `FACTORY` داخل `factory.js` ليظهر في المصنع.

## الخطوة التالية المقترحة (بالترتيب)

1. مراجعة صلة للنموذج **على أجهزة حقيقية**: هاتف وآيباد. ثم اعتماد أو تعديل المحركات والسرعات، و«نور».
2. **رفع ومراجعة `firestore.rules` الأصلي للبوابة (S-1).** هذا شرط قبل أي ربط.
3. كتابة طبقة الحفظ في Firestore (دفعات `batch` تطابق `firestore.learn.rules`) خلف مفتاح تشغيل، وتجربتها على مشروع اختبار منفصل.
4. إنتاج الأصول حسب الأولوية في ASSET_PRODUCTION_LIST.md › 6. تبدأ بنور وتسجيلات الحروف.
5. بعد اعتماد الجودة فقط: الإنتاج الواسع عبر المصنع، مع مراجعة لغوية وتربوية لكل نشاط.

## قيود سارية

- لا دمج ولا نشر.
- لا تعديل لقواعد الإنتاج.
- لا خدمات مدفوعة.
- لا بيانات أطفال حقيقية.
- لا تعديل لوظائف صلة الإدارية والمالية.
- لا نسخ لأصول أ ب ت.
