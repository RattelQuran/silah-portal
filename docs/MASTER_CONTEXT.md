## قواعد العمل الثابتة
1. لا حذف لأي وظيفة قائمة دون موافقة المالك.
2. لا تغيير للهوية البصرية دون عرض تصور بديل واعتماده.
3. لا نشر إلى الإنتاج (دمج في `main` = نشر تلقائي على GitHub Pages، أو تعديل قواعد Firestore) دون موافقة صريحة.
4. لا خدمات مدفوعة دون موافقة.
5. قبل أي تعديل جوهري: فرع استعادة `restore/<التاريخ>-<السبب>` (وسوم git محجوبة من بيئة السحابة، فنستخدم فروعًا).
6. لا أسماء أطفال حقيقية في أي مادة تسويقية (قرار سابق في مستودع الفيديوهات).
